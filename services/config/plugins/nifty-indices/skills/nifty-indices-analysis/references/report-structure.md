# Report Structure & Presentation

Reports must be concise, visually engaging, and decision-oriented. Prioritize charts, KPI cards, and tables over prose.

## 1. Quick Summary
Cover:
- Most important findings.
- Overall verdict based on the analysis.

## 2. Writing Style
- Use simple, natural language. Avoid jargon.
- Keep sentences short, with one idea each.
- Use no paragraphs where possible; prefer bullets and compact layouts.
- Never use checklist or evidence-checklist tables.
- Include only relevant information. Remove generic commentary and repetition.
- Clearly distinguish facts, estimates, and analytical opinions.
- Omit irrelevant sections rather than filling space.
- Maintain institutional research quality.

**Core principle:** Make the report scannable in under 2 minutes, not something that takes 20 minutes to read.

## 3. Visualization & Design
**Visual storytelling takes priority.** Let the analysis plan determine which figures to include.

- Prefer visual comparisons over explanatory prose.
- Use charts for price, moving averages, volume, and relative strength.
- Avoid decorative or redundant charts.
- Use real data only. Never fabricate values. State data limitations clearly.
- Use units, measure, currencies etc.
- Use distinct colors across plots, selected from this palette:

## 4. Citations & Hyperlinks
**Use inline clickable citations. Never use footnotes.**

- Link source names, figures, and meaningful phrases directly to original sources.
- Place links naturally anywhere in a sentence, including mid-sentence.
- Never display raw URLs.
- Never add a Sources column to tables.
- Avoid lengthy Sources or References sections.
- Add compact source captions beneath charts where appropriate.

**Example:**

Revenue grew 23% YoY to $2.45B, beating consensus by 2.5%, according to the [Q3 earnings release](https://example.com/earnings).

Management also raised [FY2026 revenue guidance](https://example.com/guidance) to $9.8–10.0B.
